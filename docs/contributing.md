TopbarPlus is free and open source so we appreciate all the help to improve it!

## Bugs

You can submit bug reports on the [Bugs board]. Click **Create**, then choose **TopbarPlus** under **Where**, and include the steps to reproduce it and any errors from Output.

## Suggestions

You can submit suggestions on the [Suggestions board]. Click **Create**, then choose **TopbarPlus** under **Where**, and vote for existing ideas you'd like to see.

## Pull requests

You can submit pull requests on the [TopbarPlus repository]. Please branch off `main` and keep your changes backwards compatible. For bigger changes, post a suggestion first so we can chat about it before you start (we wouldn't want to waste your time!)

## Donate

You can [donate in-game] if you'd like to support TopbarPlus. Any support is really appreciated!
